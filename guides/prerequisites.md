# 前置条件：动手前先看这份

这份文档回答三个问题：**要准备什么、有什么风险、一个月要花多少钱。**

## 一、你需要准备的东西

| 项 | 说明 | 必需 |
|---|---|---|
| QQ 小号 | **必须是另一个号，不能是常用号** | ✅ |
| 模型 API key | OpenAI 兼容接口，见下 | ✅ |
| 一台电脑或服务器 | 本地 Windows 或 Linux 云服务器 | ✅ |
| 手机（扫码） | 只在那一次登录时用 | ✅ |

### 关于 QQ 小号

- 建议**专门注册一个新号**，养几天（加几个好友、发点动态）再挂机器人
- 不要用主号，不要用绑了重要东西的号
- 小号也需要实名（腾讯要求），这点避不开

### 关于模型

需要 **OpenAI 兼容的 chat completions 接口**。教程以 DeepSeek 为例（便宜、中文好），换成别的厂商时要注意：

| 差异点 | 说明 |
|---|---|
| `modalities` | 见 [troubleshooting/tools-not-sent.md](troubleshooting/tools-not-sent.md)，漏 `tool_use` 工具会全失效 |
| `custom_extra_body` | DeepSeek 的 `{"thinking": {"type": "disabled"}}`，别家没有这个参数 |
| 视觉能力 | 表情描述、看图都要；不支持就只能纯文字 |
| embedding | 大多数 chat 模型**没有** embedding 端点，要另配（见 [plugins/local-embedding.md](plugins/local-embedding.md)） |

## 二、风险，如实说

### 第三方协议端有封号风险

NapCat 走的是 NTQQ 协议注入，**不是腾讯官方开放的机器人接口**。这意味着：

- 腾讯随时可能调整协议导致登录失效或账号被处置
- 用小号可以把损失控制在"一个小号"，但**风险无法归零**
- 低频、像正常人一样聊天能降低被识别概率，但不保证

**这条无法通过技术手段消除，只能接受或不用。**

### 唯一必须人工介入的场景

QQ 掉线后要**重新扫码登录**。脚本没法替你做，因为需要手机 QQ 确认。

掉线原因包括：腾讯踢下线、改密码、异地登录风控、长时间不活跃。

### 其他

- 机器人说的话由模型生成，可能不合适。**白名单一定要开**，别让它跟陌生人聊
- 如果放行了别人，他们消耗的是**你的** API 额度
- 私聊内容和人格设定都会发给你选的模型厂商

## 三、成本估算

### 模型调用（主要开销）

按 DeepSeek 官方价（2026 年，每 100 万 tokens，低峰价约为标价一半）：

| 项目 | 单价 | 说明 |
|---|---|---|
| 输入（未命中缓存） | $0.15 | flash 档 |
| 输出 | $0.60 | flash 档 |
| 联网搜索 | $0.75 / 1000 次 | 每次约 0.00075 美元 |

**单轮对话消耗实测**：人格 2000+ 字 + 记忆注入 + 插件提示词 + 会话历史，输入约 3000–6000 tokens，输出 100–300 tokens。

按每轮输入 4000、输出 200 算：

```
每轮 ≈ 4000 × 0.15/1M + 200 × 0.60/1M ≈ 0.00072 美元
每天 100 轮 ≈ 0.072 美元
每月 ≈ 2.2 美元 ≈ 16 元
```

加上搜索（每天 100 次 ≈ 0.075 美元/天），**一个月大约 20–40 元人民币**，取决于聊多少。

想让机器人更聪明换旗舰模型的话，价格是 flash 的 4 倍左右，同口径约 60–150 元/月。

### 服务器

| 方案 | 成本 |
|---|---|
| 本地电脑跑 | 只有电费，但电脑不能关 |
| 云服务器 4核4G 轻量 | 约 100–150 元/年（新用户价；续费可能翻倍） |
| 云服务器 2核2G | 更便宜，但跑不动本地 embedding |

### 其他服务（都可选）

| 服务 | 成本 | 用途 |
|---|---|---|
| Edge TTS | 免费 | 语音，无需 key |
| 本地 embedding | 免费（占 200MB 内存） | 长期记忆、按描述找图 |
| 付费 embedding（硅基流动等） | 约 0.1 元/百万 token | 同上，省事但要充钱 |

## 四、时间投入

| 阶段 | 熟练后 | 第一次 |
|---|---|---|
| 装 AstrBot + NapCat | 15 分钟 | 1–2 小时（下载慢、踩坑） |
| 打通链路 + 能对话 | 10 分钟 | 30–60 分钟 |
| 配人格、调说话风格 | 持续调 | 几天到几周 |
| 装插件 | 5 分钟/个 | 20 分钟/个 |
| 排查"工具不生效" | 3 分钟（知道看 `modalities`） | **一晚上**（我们就是这样） |

## 五、动手前的检查清单

```
[ ] 有一个专门的小号，不是主号
[ ] 有模型的 API key，且账户有余额
[ ] 电脑/服务器满足 Python 3.12 + ffmpeg
[ ] 知道自己的 QQ 号（要填进白名单）
[ ] 接受"掉线要重新扫码"这件事
[ ] 接受第三方协议端的封号风险
```

最后一条最重要。**如果这两条风险不能接受，这个方案就不适合你**，
应该考虑官方开放平台（虽然能力受限，但不会被封）。
